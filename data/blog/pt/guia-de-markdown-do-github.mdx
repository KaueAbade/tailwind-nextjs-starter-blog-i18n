# Introdução

A análise de Markdown e Mdx é suportada via "unified" e outros pacotes remark e rehype. O `next-mdx-remote` nos permite analisar arquivos `.mdx` e `.md` de forma mais flexível sem mexer no webpack.

É usado o GitHub Flavored Markdown. O `mdx-prism` fornece recursos de destaque de sintaxe para blocos de código. Aqui está uma demonstração de como tudo se parece.

A cola de markdown a seguir é adaptada de: https://guides.github.com/features/mastering-markdown/

# O que é Markdown?

Markdown é uma forma de estilizar texto na web. Você controla a exibição do documento; formatar palavras em negrito ou itálico, adicionar imagens e criar listas são apenas algumas das coisas que podemos fazer com Markdown. Na maior parte do tempo, Markdown é apenas texto comum com alguns caracteres não alfabéticos, como `#` ou `*`.

## Tabelas

Você pode criar tabelas montando uma lista de palavras e dividindo-as com hífens `-` (para a primeira linha), e então separando cada coluna com uma barra vertical `|`:

```
| Primeiro cabeçalho | Segundo cabeçalho |
| -------------------------------- | ---------------------------- |
| Conteúdo da célula 1 | Conteúdo da célula 2 |
| Conteúdo na primeira coluna | Conteúdo na segunda coluna |
```

| Primeiro cabeçalho | Segundo cabeçalho |
| -------------------------------- | ---------------------------- |
| Conteúdo da célula 1 | Conteúdo da célula 2 |
| Conteúdo na primeira coluna | Conteúdo na segunda coluna |

## Tachado

Qualquer palavra envolta por dois tis (como `~~isto~~`) aparecerá ~~tachada~~.
